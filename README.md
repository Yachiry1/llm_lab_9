
# Survival AI — AI-помічник із виживання

## Опис проєкту

Survival AI — це LLM-агент, який допомагає користувачам орієнтуватися в екстремальних ситуаціях: загубитися в лісі, зіткнутися з холодом, нестачею води або потребою в першій допомозі.

Агент працює у форматі чату, аналізує повідомлення користувача, самостійно обирає необхідні інструменти та надає покрокові рекомендації.

## Технології

- **Python** — реалізація логіки агента та інструментів.
- **Groq API** — взаємодія з LLM та Function Calling.
- **Gradio** — вебінтерфейс у форматі чату.
- **JSON** — зберігання інструкцій із виживання.
- **Render** — хостинг застосунку.

## Інструменти агента

Агент має шість інструментів, реалізованих як Python-функції:

1. `assess_risk()` — оцінює рівень небезпеки ситуації.
2. `check_equipment()` — аналізує доступне спорядження.
3. `get_survival_guide()` — надає інструкції для конкретної ситуації.
4. `estimate_water_supply()` — оцінює запас питної води.
5. `create_survival_plan()` — формує покроковий план дій.
6. `get_first_aid_guide()` — надає базові рекомендації з першої допомоги.

За допомогою Function Calling LLM самостійно визначає, які інструменти необхідно викликати, та використовує отримані результати для формування відповіді.

## Запуск проєкту

1. Клонувати репозиторій:

   ```bash
   git clone <repository-url>
   cd survival-ai
   ```

2. Встановити залежності:

   ```bash
   pip install -r requirements.txt
   ```

3. Запустити застосунок:

   ```bash
   python app.py
   ```

4. Відкрити локальне посилання Gradio у браузері та ввести Groq API Key.

API-ключ можна отримати на https://console.groq.com/keys.
